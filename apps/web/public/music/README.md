# 🎵 Hegemonia Music Folder

Coloque suas faixas de áudio preferidas (.mp3 / .ogg) nesta pasta:
- `track1.mp3` -> Trilha 1
- `track2.mp3` -> Trilha 2
- `track3.mp3` -> Trilha 3

O player de rádio no canto superior direito do jogo detectará e permitirá alternar entre o gerador tático ambiente procedural e seus arquivos locais!
