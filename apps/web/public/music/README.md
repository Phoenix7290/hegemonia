# Hegemonia Music Folder

Coloque suas faixas de áudio preferidas (.mp3 / .ogg) nesta pasta:
- `track1.mp3` -> Trilha Sonora Customizada

Por padrao, o Hegemonia utiliza sintese procedural Web Audio (Marcha Tatica) para garantir neutralidade ideologica e imersao sem dependencia de arquivos externos ou conteudo protegido por direitos autorais.
